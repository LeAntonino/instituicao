# instituicao
projeto POO de uma instituição academica

## como rodar o projeto
abra o projeto em uma IDE para acessar-lo
o projeto pode ser rodado a partir da classe Main, no pacote br.edu.instituicao.main, após rodada,
deverá se utilizar do console para interagir com o projeto, inserindo dados e valores numéricos quando pedido

## por que pessoa é abstrata?
a classe pessoa foi criada como abstrata pois serve como "esqueleto" para as classes aluno, professor e coordenador
o programa foi designado para gerenciar estas três classes, logo para prevenir que a classe pessoa seja instanciada diretamente,
foi declarada como abstrata
